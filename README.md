## Highlights

- ⚡ **Ultra-Fast & Featherweight**: Clean and minimalist Via Browser-style interface with instant cold start and a small footprint (~10.6 MB).
- 🛡️ **Built-in uBlock AdBlocker**: High-performance host filter defusing ads, popups, and tracking scripts in memory with zero network delay.
- 🌙 **System-Integrated Dark Mode**: Automatic dark and light theme detection matching your Android system preferences without manual intervention.
- 📑 **Ergonomic Bottom Navigation**: Via-style bottom sheet menu and responsive tab switcher designed for comfortable one-handed use.
- 🔒 **Privacy by Default**: No user tracking, no telemetry, and strict on-demand permissions (storage permissions are only requested when downloading files).
- 🔍 **Customizable Search & Shortcuts**: Default search engine set to Google, fully configurable in settings, alongside high-definition cached homepage shortcuts.
- 📥 **Integrated Download Manager**: Reliable downloads with full background handling and secure file provider support.

---

## Features

- **Ad & Tracker Blocking**: Block advertisements, banners, and malicious trackers effortlessly.
- **Incognito Browsing**: Leave no traces on your device with dedicated private browsing sessions.
- **Customizable Interface**: Personalize your homepage, search engines, and shortcuts.
- **Reading Mode**: Distraction-free reading for articles and blogs.
- **Desktop Mode**: Request desktop versions of websites with a single tap.
- **Full Screen Mode**: Maximize screen real estate while reading or browsing.
- **Smooth Gestures & Tab Management**: Fluid tab overview and intuitive gesture controls.

## Building from Source

To build yLoad locally using Android Studio or the command line:

```bash
# Clone the repository
git clone https://github.com/xxnonxxp11/yLoad.git
cd yLoad

# Build debug APK using Gradle
./gradlew assembleDebug
```

The generated APK will be available in:
`app/build/outputs/apk/stable/debug/app-stable-debug.apk`
